# Auth

Documentation admin.

### Design System BO : passe du 19/11/2026

La page publique d'activation d'invitation BO réutilise la coque `auth-shell`/`auth-card` du BO natif pour les thèmes clair et sombre. Le texte secondaire du contrôle de robustesse utilise `--bo-muted` au lieu d'un gris clair codé en dur. Le parcours d'activation, la sécurité du jeton et la soumission AJAX restent strictement inchangés. CI et CT XT exigés avant clôture.
